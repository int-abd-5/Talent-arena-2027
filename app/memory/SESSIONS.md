# Session timeline

The time axis over the memory folder. The numbered chunks are organised **by topic**, because that is how
knowledge is looked up. This file is organised **by when**, because that is how you answer "what did we do
last time, and where did it stop."

For current delivered capability read the top of
[BUILD_PROGRESS](../technical%20context/BUILD_PROGRESS.md). For unfinished work read
[SAVE_POINT](SAVE_POINT.md). [INDEX](INDEX.md) locates durable decisions. This file records milestones, not
another copy of the live backlog.

All times are Asia/Karachi (UTC+5). Session spans are bounded by commits, so a session began somewhat before its
first commit. Everything here is grounded in `git log`, not recalled.
