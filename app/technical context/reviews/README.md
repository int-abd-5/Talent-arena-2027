# Reviews

Dated reviews, findings addressed to the owner, and plans that were reviewed before being built. One file
per review, named `<topic>-YYYY-MM-DD.md`, naming the commit or document it examined. Append each finding
the moment it is confirmed, so a review cut off midway still leaves its findings behind.

A technical finding that needs a product decision goes here, addressed to Mohib, and waits for the
decision. It is not resolved silently in code or in the specification.
